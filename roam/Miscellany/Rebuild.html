Rebuild

03-10-2026

I’ve decided to rework this website. It’s still far far from great and there’s quite a few things I learned on doing things the wrong way…. which are still implemented incorrectly and inelegantly. That said, this’ll be workable for now.

Why?

Short answer: I wanted to be able to host a simpler and more lightweight site, preferrably built with a functional programming language.

Longer answer: Before, I was using Obsidian to keep notes. And the solutions I found for hosting those notes, while very faithful to the notes format, were providing lots of features which I really didn’t need or use. Hence, it always felt like I was carrying unnecessary bloat for what I wanted to put out. It also felt like anytime I wanted to update my site (such as separating the presentation of my notes from the format of the notes themselves), I had to squiggle around whatever framework I chose rather than properly learn about that maintenance myself – learning how to fish and all that. Another way to see it is that Obsidian was giving me too little friction to force me to optimize my workflow. It was too easy to stick to the defaults. It’s the same reason I could never stick with VSCode.

And now…

Updating this site has been a double-faceted endeavor. In departing Obsidian, I’ve decided to give (doom) emacs an honest effort, along with org-mode. The nice thing is that it gives one centralized hub to be “productive”, such as note-taking, coding, RSS, list ad nauseam. As far as composing these notes to build this site, I’ve decided on Haykll. Along the way I realized there’s a bunch of unorthodox choices I’m making (some even a bit embarrasing!). These choices have made things much uglier than necessary, but that’s the learning process. When enough of these get fixed, a new note will be made!
